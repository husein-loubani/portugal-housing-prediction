# Data Dictionary — Portugal Real Estate Listings

| Column | Type | Description |
|--------|------|-------------|
| Price | float | Asking price in Euros (target) |
| District | str | Administrative district (e.g., Lisboa, Porto) |
| City | str | City name |
| Town | str | Town / parish name |
| Type | str | Property type (Apartment, House, Land, etc.) |
| EnergyCertificate | str | Energy efficiency rating (A+, A, B, B-, C, D, E, F, NC) |
| GrossArea | float | Gross private area (m²) |
| TotalArea | float | Total area (m²) |
| Parking | float | Number of parking spaces |
| HasParking | bool | Whether the property has parking |
| Floor | str | Floor level (Ground Floor, 1st Floor, etc.) |
| ConstructionYear | float | Year the property was built |
| EnergyEfficiencyLevel | float | Energy efficiency numeric level |
| PublishDate | float | Listing publication date |
| Garage | float | Garage availability |
| Elevator | bool | Whether the building has an elevator |
| ElectricCarsCharging | float | Electric car charging availability |
| TotalRooms | float | Total number of rooms |
| NumberOfBedrooms | float | Number of bedrooms |
| NumberOfWC | float | Number of water closets |
| ConservationStatus | float | Conservation status rating |
| LivingArea | float | Livable space (m²) |
| LotSize | float | Land lot size (m²) |
| BuiltArea | float | Total constructed area (m²) |
| NumberOfBathrooms | float | Number of bathrooms |
